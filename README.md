

\# 🌍 CodeAlpha Language Translation Tool



A Python-based language translation application developed as part of the CodeAlpha AI Internship.



\## Features



\- Translate text between 13 languages.

\- Select source and target languages.

\- Swap source and target languages.

\- Listen to translated text using Text-to-Speech.

\- Clear input and translated output.

\- User-friendly interface built with Streamlit.



\## Technologies Used



\- Python

\- Streamlit

\- Deep Translator

\- MyMemory Translation API

\- Google Text-to-Speech (gTTS)



\## Supported Languages



English, Hindi, Telugu, Tamil, Kannada, Malayalam, French, German, Spanish, Japanese, Korean, Arabic and Chinese (Simplified).



\## Installation



1\. Clone the repository:



&#x20;  ```bash

&#x20;  git clone https://github.com/BabafirozDudekula/CodeAlpha\_LanguageTranslationTool.git

&#x20;  ```



2\. Open the project folder:



&#x20;  ```bash

&#x20;  cd CodeAlpha\_LanguageTranslationTool

&#x20;  ```



3\. Install dependencies:



&#x20;  ```bash

&#x20;  pip install -r requirements.txt

&#x20;  ```



4\. Run the application:



&#x20;  ```bash

&#x20;  streamlit run app.py

&#x20;  ```



5\. Open the local URL displayed in your terminal.



\## Note



An active internet connection is required for translation and speech generation.
